# Noon Food Delivery — SQL Business Analysis

## Project Overview
This project uses MySQL to analyse food delivery order data and answer business questions related to customer acquisition, restaurant performance, promotional campaigns, and customer retention.

## Business Questions
1. Top-performing restaurant by cuisine.
2. Daily new customer acquisition.
3. January 2025 customers who placed exactly one order.
4. Inactive customers with promotional first orders.
5. Customers reaching every third order.
6. Repeat customers who always use promotional codes.
7. Organic customer acquisition percentage.
8. Cuisine with the highest order volume.
9. Percentage of orders using promotional codes.
10. Repeat customer rate.
11. Average orders per customer.
12. Delivered versus cancelled order percentages.
